OVERLEAF SOURCE PACKAGE

Main document: main.tex
Supplement: supplement.tex
Compiler: pdfLaTeX; bibliography processor: BibTeX.

Upload the ZIP to a new Overleaf project. Select main.tex as the main
document. To compile the supplement, change the main document to
supplement.tex. Keep the support/, figures/ and evidence/ directories.
No shell escape, external figure downloads or custom fonts are needed.

The source package includes the manuscript, supplement, vector figures,
bibliographies and compact frozen evidence records. It does not include
large observation arrays, model checkpoints or all experiment code.
The figure-building script needs the local experimental repository;
the generated figures and tables are already included for compilation.

The original manuscript and all earlier experiments remain unchanged.
This version adds references on compact learned estimators and prepares
a matched comparison with a 148-parameter NA-ALISTA-inspired recurrent
control. Final new numerical results must be inserted only after the
new experiment has completed and passed its saved audit. Earlier
OptShrink wins, stress failures and unsuccessful hybrids are retained.

AUTHOR ACTIONS BEFORE SUBMISSION

1. Read and approve every claim, equation, author detail and figure.
   Automated checks are not a substitute for author responsibility.
2. The intended venue is IEEE Transactions on Communications. Apply its
   current page limit, disclosure and supplementary-file rules.
3. Papers 1 and 2 are unpublished and are being combined into one
   submission. Do not submit overlapping standalone versions in parallel.
   Disclose any related submissions or prior dissemination to the editor.
4. Assign an actual permanent public code/data URL or archival DOI and
   replace the reproducibility statement accordingly. No fake URL is used.
5. Confirm the AI-assistance disclosure against actual use and the venue's
   policy. The package records drafting, coding and figure-script assistance;
   it does not imply that human review has already been completed.
6. Confirm the email, affiliation, ORCID, conflicts, funding statements
   and any institutional approval required for submission.

The evidence supports conditional simulation-based claims. It does not
establish hardware performance, universal superiority, full-estimator
convergence, optimality of cubic shrinkage, or a published-URformer
reproduction. A submission package is not a guarantee of acceptance.
