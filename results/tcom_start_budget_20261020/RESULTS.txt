CONTROLLED START COMPARISON: PRE-TEST 40-UPDATE REVISION

The originally frozen 100-update plan failed its runtime calibration before any fresh test data were generated. All five start families exceeded the literal 10.74 ms cap at 100 updates; no candidate in the original 100/125/150/175/200 menu was eligible. Those sources and failed calibration remain unchanged in tcom_start_ablation_20261020.
This separate study reduces the common continuation uniformly to 40 updates for every start and uses one prespecified 40/50/75/100 budget calibration. This is a change in computation, not a new name for the same pipeline. The trained adaptive/global weights, raw starts, classical calibration scores and selected classical configuration are reused unchanged; no additional training or classical recalibration was performed. Fresh test and BER seeds were untouched when this revision was frozen.

FRESH COMMON-40 ACCURACY COMPARISON
Against the trained global schedule, the whole-grid common-40 comparison supports higher error for the adaptive start in NMSE and supports lower error for the adaptive start in BER.
Against the calibrated classical structured start, the whole-grid common-40 comparison supports lower error for the adaptive start in NMSE and does not resolve an error difference at the adjusted confidence level in BER.
At ordinary SNR, the adaptive start changes from -20.21379 dB before refinement to -15.40568 dB after the forced continuation and final filter (+4.80810 dB change; positive is worse). The frozen latest estimator has -20.21379 dB in the same region.
The forced-continuation experiment is a controlled comparison, not a recommendation to replace the frozen latest estimator.

Every experimental start is used at every condition, followed by the same 40 exact EM updates and final noise/reference-dependent filter. The global control learns 30 per-stage constants offline and has no observation-conditioned controller; its relative thresholds retain scale normalization. The classical control uses one configuration selected from the prespecified validation grid. Classical calibration minimizes raw-start held-out likelihood loss, rather than loss after the 40-update continuation. The common final filter was inherited from earlier adaptive-led selection, so this comparison is conditional on that fixed filter. The control does not equalize model parameter count. This comparison does not select or replace the deployed estimator.
Forty denotes the continuation, not total EM-style stages: adaptive, global, classical and EM10 starts each execute ten initial stages before the forty additional updates; the spectral initializer has no initial EM stage and receives forty updates. Runtime includes the entire pipeline. This finite-tail comparison evaluates these receivers, not the best converged likelihood solution or every classical estimator.
The primary grid gives equal weight to 153 condition scores, including 108 conditions above 20 dB although training ends at 20 dB. It is not a deployment-weighted average. The pooled ratio of summed errors to summed channel energy uses different weighting and can reverse a close ranking; both versions are shown below.

INTERPRETATION AND VERIFICATION
The test contains 128 anchors for each of nine reference/path combinations: 1,152 physical anchors reused across 17 SNR values, and 384 index clusters for the coupled bootstrap. Each channel transmits all 64 joint Gray-QPSK vectors once, with independent data noise shared across estimators. Every detector observes magnitudes only and evaluates the same 64-hypothesis exact Rician likelihood.
The simulated receiver has N=32 antennas, K=3 users and P=30 fitting pilots, with known reference and noise variance. The tested range and these assumptions limit generalization.
NMSE is the equal-cell mean of dB ratios of summed channel errors to summed channel energy. BER averages the same channel samples. The 20,000 paired bootstrap draws share local indices across references and SNR within each path regime. Intervals are conditional on the fixed trained weights, calibrated controls and study grid.
Zero observed errors, zero-versus-zero differences and collapsed empirical intervals do not establish zero population BER, statistical equivalence or population noninferiority. Bit counts are not independent channel trials.
Classical configuration: {"beta": 1.0, "c": 1.0, "kind": "noise"}.
Required audits passed: selection, test predictions, raw/final summaries, both timing windows, and BER. The BER audit independently regenerates data and redecodes every method on the prespecified spot cases. This report does not edit the manuscript or make a publication/novelty claim.
