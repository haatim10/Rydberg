7.1 Canonical formulation and the conjugation

Cui's solver addresses the canonical problem z = |MHu + b + w| with M known, u unknown. Our problem is a matrix equation; the adapter works one receive element at a time. Row n of eq. (8) reads Zn,: = |gnS + Bn,: + Wn,:| where gn is row n of G — a length-K row vector. The difficulty is that gnS is a row-times-matrix product whereas the solver expects MHu, a matrix-times-column product.

Transposing gives (gnS)T = STgnT, and ST = (SH)*. Conjugating the whole equation turns STgnT into SHconj(gn), which is exactly the required form — at the price of conjugating everything else in the same equation. Since |conj(·)| = |·|, the measurement Z is untouched. Hence:

A trap that an earlier draft of this document fell into

The dual convention (M = conj(S), u = gn, b = Bn,:, no output conjugation) is equally valid — also verified at 8.88e-16. What is not valid is conjugating both M and u: that fails at a deviation of 4.043. An earlier version of this write-up printed exactly that invalid pair. Three regression tests now pin all three cases. Note also that the identity only closes when the noise is carried into the canonical b alongside B.

7.2 Biased Gerchberg–Saxton

Step 1 — initialisation. A spectral initialiser, weighted by zq (not zq²), on the augmented vectors m̄q = [mq; bq]:

Mspec = Σq zq m̄qm̄qH,    v = principal eigenvector(13)

The eigenvector fixes only a direction. Two further steps, both present in the code and both easy to omit, fix its magnitude and its global phase:

r̄ = |M̄Hv|Tz / ‖M̄Hv‖²,   ū0 = r̄ v(14)
u0 = [ e−j∠(ū0)D+1 ū0 ]1:D(15)

Eq. (14) is a magnitude least squares picking the scale that best matches the measured amplitudes. Eq. (15) is the phase anchor: the (D+1)-th entry corresponds to the known reference, whose coefficient is 1 and whose phase is therefore zero by construction, so de-rotating by it pins the otherwise arbitrary eigenvector phase. Only then is the last entry dropped. A regression test confirms removing this step measurably degrades the initialiser at low SNR.

Steps 2–6 — the iteration. At iteration t:

(2) λt−1 = MHut−1 + b     (3) θt = ∠λt−1(16)
(4) yt = z ⊙ ejθt     (5) rt = yt − b(17)
(6) (MMH) ut = Mrt(18)

Interpretation. The algorithm alternates between two things it believes. It believes the measured magnitude — so it keeps z exactly and never modifies it. It does not know the phase, so it borrows the phase from its current channel estimate (step 3), pastes it onto the measured magnitude (step 4) to synthesise a complex field it can work with, subtracts the known reference (step 5), and re-solves an ordinary linear least squares (step 6). Then it repeats: a better channel gives a better phase guess, which gives a better synthetic field.

Step 7 — stopping. No convergence test. A fixed budget of t₀ = 50 iterations, matching Cui. Eq. (18) is solved via the normal equations, never by forming an explicit inverse.

7.3 EM-GS

Same phase and least-squares steps; the difference is step 4. Instead of pasting the raw measured magnitude onto the guessed phase, EM-GS uses the conditional mean of the true amplitude given the measurement — a soft, SNR-aware replacement for the hard magnitude substitution:

R(κ) = I1(κ)/I0(κ),    κ = (2/σ²) z ⊙ |λ|,   yt = z ⊙ R(κ) ⊙ ejθt(19)

Statistical motivation. Conditional on the noiseless field λ, the measured amplitude z is Rice-distributed. The posterior mean of the underlying complex field, given z and λ, involves the ratio of modified Bessel functions I1/I0. Plain GS is the limiting case that trusts z completely; EM-GS shrinks it toward the model prediction by a factor R(κ) ∈ [0,1] that measures how reliable the measurement is.

Behaviour at the two limits. R is monotone increasing with R(0) = 0 and R(κ) → 1. At low SNR or low RSR, κ is small, R < 1, and the measurement is discounted — this is where EM-GS wins. At high SNR or high RSR, κ saturates, R → 1, and EM-GS becomes GS. This is not a conjecture: measured EM-GS advantage over GS is +1.3 dB at RSR = 0 dB and +0.00 dB at RSR = 24 dB (Figure A3).

Numerical stabilisation. R is computed with exponentially scaled Bessel functions (scipy.special.ive) so the shared e−|κ| factor cancels; forming I₁/I₀ directly overflows at realistic high-SNR κ. Above κ = 10⁴ the asymptotic expansion R(κ) ≈ 1 − 1/(2κ) − 1/(8κ²) is used, and R(0) = 0 exactly. Output is confined to [0,1]. Checked against SciPy and against the quadrature definition of In.

Check against Cui. verified The Bessel-ratio form, the κ definition and the t₀ = 50 budget match Cui's Algorithm 2 as published in the supplied paper. Track A independently reproduced Cui's own figures with this code.

7.4 Computational complexity

Per channel realisation, with t0 iterations and the adapter looping over N receive elements:

GS, EM-GS:   t0 · N · O(K²P)(20)

The K×K Gram matrix SSH is shared across rows and across iterations, so the per-iteration cost is dominated by forming M r and one K×K solve. EM-GS adds one Bessel evaluation per measurement, which is O(NP) and cheap relative to the algebra. Measured medians at P = 30, SNR = 5 dB: GS 30.7 / 60.9 / 118.6 ms and EM-GS 91.9 / 190.9 / 368.9 ms at N = 8 / 16 / 32 — both scaling linearly in N, as eq. (20) predicts.

The linearised (Xu-type) method — related work

Status: RELATED WORK ONLY — not part of finalised Track B

The code contains linearised_closed_form_ls, but a runtime tripwire confirms it is called 0 times by any Track-B estimator across all array sizes. It appears in no Track-B result. not verified The Xu paper was not supplied. The derivation below is from first principles and from the code's own docstrings; the code explicitly states its constants are derived, not copied from Xu. Do not attribute any specific prefactor, algorithm variant or figure to Xu on the strength of this section.

Start from the scalar biased magnitude measurement z = |b + x| and square it:

z² = |b|² + 2|b| ℜ{e−j∠bx} + |x|²(21)

Now impose the strong-reference assumption |b| ≫ |x|. The three terms scale as |b|², |b||x| and |x|². The last is smaller than the middle one by the factor |x|/|b| ≪ 1, so the quadratic term |x|² is discarded, leaving

z² − |b|² ≈ 2|b| ℜ{e−j∠bx}(22)

What has happened. The right-hand side is linear in x — but only in one real direction. What is measured is the projection of x onto the reference phase axis ej∠b; the orthogonal component is invisible to first order. So each measurement supplies one real linear equation, and with enough pilot instants the collection becomes an ordinary real linear least-squares (or a gradient-descent) problem in the real and imaginary parts of G. That is why linearisation permits GD or LS where the exact model does not.

When it breaks. The discarded term is |x|². Its relative size is governed by RSR: at high RSR it is negligible and the approximation is excellent; as RSR falls it becomes comparable to the retained term and the model is simply wrong. So the linearisation is accurate exactly where the problem is easy, and fails exactly where exact methods are needed.

Why exact GS/EM-GS can beat it. GS and EM-GS never discard |x|² — they work with eq. (8) as written. At low RSR that retained term carries real information about G. not verified A direct head-to-head comparison of exact versus linearised on this ULA channel has not been run in Track B, so this paragraph is a statement about the models, not a measured result. Producing that comparison is a recommended experiment (§XX).

Exact vs approximate, stated plainly. Exact model: Z = |GS+B+W|, nonlinear, non-convex, solved iteratively. Xu-type approximation: Z² − |B|² ≈ 2|B|ℜ{e−j∠BGS}, linear, convex, solved in closed form — valid only for |B| ≫ |GS|.
