Part XIX

Status of the work

19.1 Established — safe to state in a review

  • The full simulation chain matches the frozen system model: exact modulus observation, Cui's SNR and RSR conventions, constant zero-phase reference, uniform-in-θ AoAs, non-orthogonal Gaussian pilots. All verified against code, not description.
  • Cui's biased-GS and EM-GS are reproduced as row adapters and behave as theory predicts: EM-GS above GS by an RSR-dependent margin that collapses to 0.002 dB as R(κ) → 1.
  • HS-GS's advantage over EM-GS scales monotonically with array size: −0.19 / +0.78 / +2.85 dB at N = 8/16/32, with non-overlapping paired CIs between N = 16 and 32 at all 12 shared operating points.
  • The mechanism is the one claimed: the gain decays monotonically to zero as the path count approaches the Hankel rank cap, in a controlled experiment whose hypothesis was recorded first.
  • The unconstrained CRLB is flat in N, EM-GS nearly attains it at high SNR, and the constrained CRLB is 0.88–9.85 dB below it. Both bounds were re-derived for this measurement model.
  • A real defect in the previously shipped CRLB was found and corrected (rank-2 → rank-1 per magnitude measurement), and the corrected bound is the one used everywhere.

19.2 Partially established — state with the caveat attached

  • That the gain is attributable to the projection rather than the EM step. Strongly suggested by the RSR sweep; no direct ablation with exact_step = "gs" across the full grid was run.
  • That shrinkage bias explains the CRLB crossings. The pattern matches on every axis tested, but no formal bias/variance decomposition was computed per operating point.
  • That N = 8's failure is a bias floor. Consistent with the monotone SNR trend and with the rank cap of 4, but inferred from the trend rather than measured directly.
  • That HS-GS costs no more than EM-GS. True at these dimensions (0.5–3.8% against a chained baseline) and false asymptotically, where the N³ SVD term dominates.

19.3 Not established — do not claim

  • Any behaviour under a clustered channel. Never tested. §14.4.
  • Convergence of the HS-GS iteration. No proof, no merit function, non-convex constraint set, approximate projection.
  • Any comparison against a learned estimator. None exists in this repository.
  • Optimality of any hyperparameter. cadzow_iter = 4, select_iter = 20, val_frac = 0.3, project_every = 1 were fixed at their initial values and never tuned — deliberately, since tuning them would have made the comparison against untuned baselines unfair. No claim is made that they are good choices.
  • Unequal-power users. All βk = 1; no near-far effect tested.
  • Wideband / frequency-selective operation. The model is flat and narrowband.

19.4 Known to be missing

  • The Xu paper and the Xiao/URformer paper. Parts VIII, XV are written from implementation and first principles only and are marked NOT VERIFIED throughout.
  • Per-user model-order selection. The shared scalar L̂ is a genuine limitation (§9.6, Q7).
  • A compiled PDF of tex/formulae.tex. The file is 1,197 lines / 57 equations and was structurally validated, but no TeX distribution is available in this environment, so it has never been compiled. NOT VERIFIED — NEEDS CONFIRMATION that it typesets cleanly.
  • BCa bootstrap intervals (percentile intervals only, Q17).
