  1. Step-0 audit of the frozen model (21 checks) — before any Track-B estimator was run.
  2. B3 (36 points, 18,400 trials), B4 (6 points), B6 (10 points), with five ambiguous B3 points extended from 400 to 1,200 trials by a rule fixed in advance.
  3. External review; 20 fixes applied.
  4. Adversarial final audit — 51 checks, 0 failures. Three checks failed on first run and in all three cases the expectation was wrong, not the code: a trailing-newline comparison, a CRN-pairing assumption the frozen RNG design never provided, and a trial-count identity that predated B6.
  5. CRLB re-derivation. Found a real defect in the shipped unconstrained bound (rank-2 where the likelihood gives rank-1), confirmed two independent ways, corrected. Added the constrained bound with an orthonormal tangent basis after discovering Jacobian rank deficiency at N = 8.

All drivers checkpoint per point and skip completed trial indices, so a rerun is idempotent and an interrupted run resumes without recomputing. Every stored .npz holds the per-trial numerator and denominator separately, so any pooling, subset or bootstrap in this document can be recomputed from the stores without rerunning the Monte Carlo.

D.4 Where a reader should be most sceptical

Stated plainly, because a document that lists only its strengths is not an audit. In descending order of how much they should worry a reviewer:

  1. Model class. One channel model, never varied. §14.4 and the rank-1 next experiment. This is the largest unquantified risk in the work.
  2. The N = 8 sign ambiguity. Real, reported, and explained (§16.2), but it does mean the smallest array size does not support the headline claim.
  3. No convergence theory. §19.3. The estimator is defined by what the code does at a fixed budget, not by a fixed point it provably reaches.
  4. Shared model order. A known misspecification present in every reported number (§9.6, Q7).
  5. Two papers never supplied. Parts VIII and XV rest on implementation and first principles alone and are labelled as such.

None of these is fatal to the central result — that the HS-GS advantage scales with array size and vanishes exactly when the structural constraint becomes vacuous — because that result is established by a controlled experiment against a pre-recorded hypothesis, and is corroborated by an independent bound. All of them constrain how widely it may be stated.
