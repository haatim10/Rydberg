Part XIV

Relation to clustered channel models (Saleh–Valenzuela / 3GPP TR 38.901)

Track B does not use a clustered channel. This section states precisely what it does use, how that relates to the clustered models, and — the part that matters for defending the result — which conclusions would survive a change of channel model and which would not.

Verification status

The Saleh–Valenzuela paper was not supplied and is not in the repository. The statements below about SV are standard textbook properties of the model, not readings of a source document; anything requiring the original paper's exact parameterisation is NOT VERIFIED — NEEDS CONFIRMATION. 3GPP TR 38.901 was supplied and is implemented — but in Track A, not Track B.

14.1 What Track B actually uses verified

A flat, narrowband, unclustered geometric multipath model: Lk resolvable paths per user, each with an i.i.d. uniform AoA on [−π/2, π/2] and an independent 𝒞𝒩(0, βk/Lk) gain (Part II, eq. 4). There is no delay dimension, no cluster grouping, no intra-cluster angular spread, no per-cluster shadowing, and no polarisation. Every path is an independent draw.

14.3 What this means for the Hankel low-rank assumption

This is the load-bearing question, and the answer is more favourable to HS-GS than one might fear, for a reason worth stating carefully.

Kronecker's theorem says the Hankel matrix of a channel column has rank exactly equal to the number of distinct complex exponentials ejψ present. Under Track B's model that count is Lk, because the AoAs are i.i.d. continuous draws and are almost surely distinct. Under a clustered model the number of rays is much larger — 23 clusters × 20 rays = 460 in the Track-A 38.901 configuration — but the rays within a cluster occupy a ±5° window, so their ψ values are tightly packed. The Hankel matrix is then not exactly low rank, but its singular values decay rapidly: it is numerically low rank with an effective order close to the number of clusters, not the number of rays.

So the qualitative mechanism (§9, Figure C1) survives; the exact rank cliff does not. Three consequences follow, and they cut in different directions:

  • Favourable: the effective rank under clustering is governed by cluster count, which is typically smaller than 460 and can be comparable to Lk ∈ {3,…,7}. The low-rank prior is not obviously weaker.
  • Unfavourable: Cadzow's hard SVD truncation to rank L̂ is exactly right for an exactly-low-rank signal and is a bias-inducing approximation for a rapidly-decaying one. Truncating discards the intra-cluster angular spread, which is real signal. The shrinkage bias already visible at N = 8 (§16.4) would get worse.
  • Unknown: the held-out-pilot order selector (§9.6) chooses L̂ by predictive residual, so it might adapt to the effective rank on its own. It might equally chase the slowly-decaying tail and over-select. NOT VERIFIED — NEEDS CONFIRMATION: this has not been tested and cannot be inferred from the present results.

14.4 Honest scope statement

Do not over-claim

Every Track-B number in this document was produced under an i.i.d. uniform-AoA geometric model with equal per-path power. No result here establishes anything about HS-GS under a clustered channel. The correct claim is: "under a sparse geometric multipath model, exploiting the Hankel low-rank structure of the ULA response yields up to 2.85 dB over EM-GS at N = 32." The claim "HS-GS improves RAQR channel estimation" is not supported by this evidence and should not be made. Running B3 under the Track-A 38.901 generator is the single highest-value next experiment (§20) precisely because it is the experiment that could falsify the result.

15.1 What is verifiable verified

There is no learned estimator anywhere in this repository. A grep for any deep learning framework returns nothing; the three estimators are biased-GS, EM-GS and HS-GS, all model-based and all deterministic given the realization. No training data was generated, no network was trained, and no comparison against a learned baseline was run. Any figure or table in this document that appeared to compare against URformer would be fabricated; none does.

15.2 What can be said from first principles

Two structural observations about where a learned estimator would and would not have an advantage on this problem, both of which follow from the analysis already done and neither of which requires the paper:

  • The information-theoretic ceiling is the same. The constrained CRLB of §10.7 is a property of the likelihood and the structural manifold, not of the estimator. A learned estimator trained on this exact generative model is subject to it in the same asymptotic sense that HS-GS is, and cannot beat it while unbiased. The 0.32–8.85 dB gap between HS-GS and that bound (§16.3) is therefore an upper bound on what any method — learned or not — could gain over HS-GS on this model, and it is the number that determines whether pursuing a learned estimator is worthwhile.
  • Where a learned method would plausibly win. HS-GS's two weakest links are both things a network could sidestep: the single shared scalar L̂ imposed on all K users (§9.6, a real limitation — the true orders were (7,4,6) and the selector chose 5), and Cadzow's hard rank truncation, which is the wrong operator for a numerically-rather-than-exactly low-rank signal (§14.3). A learned prior has neither constraint. That is an argument for why the comparison is interesting, not evidence about its outcome.
  • Where it would plausibly lose. A network trained on 𝒰[−π/2, π/2] i.i.d. AoAs inherits that training distribution. HS-GS's assumption — "the column is a sum of L exponentials" — is weaker and model-agnostic in a way a trained prior is not.

15.3 What would be required to make a real comparison

Recorded so the scope of the missing work is explicit, not so it is proposed: the URformer paper itself; its exact observation model (in particular whether it estimates from the non-linear modulus Z or from a linearised/complex observation — if the latter, the comparison is not like-for-like and this document's central no-linearisation constraint would make a direct NMSE-vs-NMSE plot misleading); its training/test split; and matched SNR, RSR, N, K, P and Lk conventions. Absent all of these, the correct statement in a review is: "a learned baseline was not run; the constrained CRLB bounds what one could achieve on this model."
