16.8 B7 — the mechanism tested directly (controlled path count)

Every other experiment draws Lk ~ 𝒰{3..7} at random, so none of them isolates path count. B7 fixes Lk = L identically across users and sweeps it from very sparse up to the Hankel rank cap, at N = 32, P = 30, SNR = 5 dB, RSR = 12 dB, 400 trials per point, with the identical CRN world function, estimators and hyperparameters as B3.

Hypothesis, recorded in the script before the run

"L increases → Hankel rank increases → the strict low-rank prior carries less information → the HS-GS advantage should shrink, and should vanish once L reaches cap(N) = ⌈N/2⌉, where the constraint is vacuous."

The prediction is confirmed, with one refinement that is worth more than the confirmation. The gain decays strictly monotonically across all eight points — +7.13 → +3.58 → +1.84 → +1.03 → +0.59 → +0.27 → +0.04 → −0.12 dB — and the win rate falls from 100.0% to 45.3%, i.e. through a coin flip. The null is reached at L = 14, where the gain is +0.04 dB with a confidence interval [−0.05, +0.12] that straddles zero. That is one grid point before the predicted L = cap(32) = 16, and at the cap itself the gain is mildly but significantly negative: −0.12 dB, CI [−0.195, −0.041], excluding zero.

The refinement is not a failure of the prediction; it is the same shrinkage mechanism appearing a third time, and it is quantitatively accounted for by the selector column. Mean L̂ rises from 2.12 at L = 2 to only 11.55 at L = 16 — it tracks the true order but increasingly under-selects, falling 4.5 short at the top of the sweep. So at L = 16 the constraint is not vacuous as the naive reading of "L reaches the cap" assumes: it is still active in 90.3% of trials, and what it is doing there is truncating away real signal. A projection that removes true channel energy costs a little accuracy, which is exactly the −0.12 dB observed. The theoretical prediction concerns L̂ = cap; the experiment sweeps the true L, and the two coincide only if the selector is unbiased, which §16.4 already established it is not.

Why this is nonetheless the cleanest evidence in the study:

  • It is a controlled experiment, not an observational trend. L is set, not drawn, and everything else — N, P, SNR, RSR, seeds, hyperparameters — is held fixed. Nothing else in Track B has this property.
  • The prediction was quantitative and pre-recorded, in the script's docstring before the run. Not merely "the gain should fall" but "it should reach zero near L = 16". A mechanism that was really something else — better initialisation, incidental regularisation, a lucky hyperparameter — had no reason to produce a null anywhere near that value.
  • It eliminates the main rival explanation. If HS-GS's advantage were generic denoising, it would persist at large L, where the estimate is just as noisy and the denoising opportunity just as large. Instead it disappears and then reverses. Generic denoising cannot produce that.
  • The baselines confirm the control worked. EM-GS is flat across the sweep (−10.62 to −10.76 dB, range 0.14 dB): path count does not affect an estimator that ignores structure. Had EM-GS moved, the sweep would have been confounded.
