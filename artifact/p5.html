Part IX

Proposed structure-aware extension — HS-GS

Attribution

Everything in this Part is proposed work, not Cui's. Cui supplies the exact measurement update (§VII) and nothing else here. The structural prior, the projection, the placement of the projection inside the iteration, and the order-selection rule are all new. HS-GS should never be described as “Cui's method with a tweak”.

9.1 Motivation

Write the ULA channel column of eq. (4) with zℓ,k = e−jψℓ,k:

gk[n] = Σℓ=1Lk αℓ,k zℓ,kn(23)

The channel across the array is a sum of Lk geometric sequences. A length-N vector of that form occupies a set of dimension 3Lk (one angle, one complex gain per path) inside an ambient 2N-real-dimensional space. At N = 32 that is roughly 45 real parameters inside 192 — a factor of 4.3 of redundancy that an unstructured estimator ignores entirely.

The key observation: Cui's estimator is row-separable — element n is recovered from zn alone. The structure in eq. (23) is a coupling along n, i.e. exactly the direction an unstructured row-wise sweep cannot see. This is verified, not asserted: perturbing one row of Z leaves every other row's estimate bit-identical. It is also why the EM-GS baseline is flat in N to 0.012 dB (§XIII).

9.2 Hankel construction verified

For a length-N sequence and a pencil parameter p, the implemented Hankel operator takes overlapping windows:

[ℋp(g)]i,j = gi+j,   shape (N−p) × (p+1)(24)

Explicitly, for g = [g₀, g₁, g₂, g₃, g₄, …]:

ℋ(g) = [ g0 g1 g2 ⋯ ;   g1 g2 g3 ⋯ ;   g2 g3 g4 ⋯ ; ⋯ ](25)

Constant along anti-diagonals. The implementation chooses p to maximise the achievable rank:

Npencil pℋ shaperank cap ⌈N/2⌉
835 × 44
1679 × 88
321517 × 1616

The adjoint used to return to a sequence averages each anti-diagonal — the exact orthogonal projection onto the Hankel subspace.

9.3 Rank derivation

One exponential. If g[n] = α zn, then ℋ(g)i,j = α zi+j = (α zi)(zj), an outer product of two vectors. Rank exactly 1.

L exponentials. Superposition of eq. (23) gives, with vℓ = [1, zℓ, …, zℓN−p−1]T and wℓ = [1, zℓ, …, zℓp]T:

ℋ(g) = Σℓ=1L αℓ vℓ wℓT ⟹ rank ℋ(g) ≤ L(26)

Assumptions required, stated explicitly. (i) The zℓ are distinct — two coincident angles collapse two rank-1 terms into one and the rank drops. (ii) All αℓ ≠ 0. (iii) Equality (rather than ≤) additionally requires L to be strictly below the pencil bound, so that vℓ and wℓ are each linearly independent Vandermonde families.

This is a RELAXATION, not a characterisation of a ULA channel

Eq. (26) admits any distinct non-zero complex zℓ. The ULA model requires |zℓ| = 1 — the angles are real. The rank constraint imposes no unit-modulus condition, so the feasible set strictly contains the set of physical ULA channels and admits damped and growing modes. Verified by counterexample: at N = 16 a sequence built from modes with |z| = 0.75 has Hankel rank 4 — identical to a physical channel with 4 paths. Correct wording throughout: a grid-free low-rank Hankel relaxation of ULA structure.

How loose is it in practice? Measured by running ESPRIT on the converged estimate at N = 32 and recording ||zi|−1|: median 0.0124, with 87.2% of modes within 0.05 of the unit circle and 96.3% within 0.10 — against a true-channel floor of median 0.0000. So the relaxation is tight in practice, but the tail is real (p99 = 0.177, max = 0.720).

9.4 Cadzow — exactly what is implemented

Audited step by step. One call performs nit = 4 passes of:

  1. Hankelisation — form ℋp(g), eq. (24).
  2. SVD of that matrix.
  3. Rank truncation to L̂: keep the top L̂ singular triplets.
  4. Reconstruction of the truncated matrix.
  5. Anti-diagonal averaging back to a length-N sequence.
  6. Iterate — steps 1–5 repeated 4 times.

What each projection accomplishes. Step 3 is the exact Frobenius-norm projection onto the set of rank-≤L̂ matrices (Eckart–Young–Mirsky). Step 5 is the exact orthogonal projection onto the linear subspace of Hankel matrices. Neither set is convex-and-affine simultaneously, so a single pass lands in neither; alternating between two exact projectors drives the iterate toward their intersection — which is precisely the set of length-N sequences expressible as L̂ exponentials. If L̂ ≥ cap(N) the routine returns g unchanged: a literal no-op, verified.

Why Cadzow and not OMP or ESPRIT. All three variants exist in the codebase (track_b_prototype.py exposes angular / hankel / esprit) and the choice is structural rather than empirical. Angular OMP discretises ψ onto a grid, so it carries an irreducible off-grid bias even on noiseless, exactly-structured data. ESPRIT is grid-free and is near-exact on data that lies exactly on the ULA manifold — measured: its recovered modes deviate from the unit circle by a median of 4.0 × 10−6 on the true channel — but it is a parameter estimator, not a projection: it is not idempotent and has no variational characterisation, so composing it into an alternating scheme has no fixed-point theory at all. On estimated (rather than exact) channels the same measurement gives a median mode deviation of 0.012 with a p90 of 0.057 and a worst case of 0.72, i.e. its output is frequently far off the manifold it is supposed to parameterise. Only Cadzow is simultaneously grid-free and a genuine alternating projection between two closed sets with exact projectors, which is what allows it to be composed into the iteration below.

Mode-deviation figures: results/track_b/modulus_tightness.json (N = 32, P = 30, SNR = 5 dB, 80 trials, 1,146 modes).

9.5 HS-GS pipeline verified

Audited: the projection is applied after every exact measurement update (project_every = 1), not as post-processing and not on a separate schedule.

Gt = (P𝒮(L̂) ∘ TEM-GS) (Gt−1),   t = 1 … t0(27)
Algorithm HS-GS  (as implemented)
  input   Z, S, B, sigma2
  1  L_hat, _ <- select_order_heldout(Z, S, B, sigma2)     # sec 9.6
  2  G <- None                                             # spectral init on first call
  3  active <- (L_hat < cap(N))                            # strict
  4  for t = 1 .. 50:
  5      G <- em_gs_channel_rows(S, Z, B, sigma2,
                                 max_iter=1, G0=G)         # ONE exact Cui update
  6      if active:
  7          for k = 1 .. K:
  8              G[:,k] <- cadzow_project(G[:,k], L_hat,
                                          n_iter=4)        # sec 9.4
  9      record residual  || Z - |G S + B| ||_F^2
 10  return G, L_hat, active

Exactness of the chaining. Calling the validated solver 25 times with max_iter=1 and a warm start reproduces one max_iter=25 call bit-for-bit, and with the projection disabled HS-GS equals validated EM-GS to 0.00e+00. So no GS mathematics is reimplemented.

Why the projection must be inside the loop. Projecting once and then running GS to convergence does nothing measurable: the gain decays monotonically with the number of unconstrained iterations after projection — +1.30 dB at 1, +0.06 at 10, exactly 0.00 at 50. Empirically the unconstrained iteration returns to its own fixed point, which the projection then cannot influence. No contraction or convergence property is claimed; alternating-projection schemes of this kind are not contractions in general.

9.6 Rank selection — mandatory disclosure

HS-GS does NOT use oracle rank

Audited directly: hs_gs_auto never receives, reads or references the true Lk. The order is chosen from a held-out pilot residual using only observable quantities. In the audit run the selector returned L̂ = 5 while the true path counts were (7, 4, 6) — it is estimating, and imperfectly. These experiments are NOT oracle-rank HS-GS.

The in-sample residual cannot be used as the criterion: a projection constrains G to a smaller set, so it can only fit the fitted pilots worse, and the in-sample criterion therefore always prefers the largest L. Measured failure of that approach: ΔJ > 0 while ΔNMSE < 0, with sign agreement of only 1–8 out of 10. The implemented rule splits the pilot columns, |𝒱| = max(1, ⌈0.3P⌉), and scores on the held-out half:

L̂ = argminL∈{1…cap(N)} ‖ Z:,𝒱 − |Ĝ(L)S:,𝒱 + B:,𝒱| ‖F²(28)
A limitation of the current design, found in this audit

L̂ is a single scalar shared by all K users. The true path counts differ per user — in the audited trial they were (7, 4, 6) — but one order is selected and applied to every column. A per-user order would match the generative model; the current implementation does not do this. This is a plausible part of why HS-GS sits 1–9 dB above the constrained bound (§X.7), and it is the cheapest concrete improvement available (§XX).

Realistic alternatives that were not implemented, and must not be described as if they were: singular-value thresholding on ℋ(ĝ), MDL, AIC. MDL was in fact tried early and performed poorly on this problem (12–18 correct out of 40 on clean data), which is why the held-out rule was adopted.

9.7 Fairness and ablation

What is already established about the source of the gain:

  • verified Not oracle rank — §9.6.
  • verified Not a baseline artefact — EM-GS is flat in N to 0.012 dB, so the N-dependence is not the baseline degrading.
  • verified Not outlier-driven — removing the worst 5% of EM-GS trials moves the gain by a median of −0.05 dB.
  • verified Structural, not incidental — when the constraint is inactive HS-GS is EM-GS bit-for-bit. Restricting to active trials does not rescue the N = 8 deficit into a clean win either way: the deficit is a per-operating-point average (§16.2), and it is concentrated at high SNR. This is what a genuinely structural mechanism should do.

not verified What is not separated: how much of the gain is improved phase retrieval (better fixed point) versus structural denoising (variance reduction on a fixed estimate). The ablation that would settle it — run Cadzow as pure post-processing on a converged EM-GS estimate (project_every = 50) and compare against the interleaved configuration — has not been run. No project_every ablation data exists in the repository. Until it is run, "the gain comes from interleaving rather than from post-hoc denoising" is an argument (§Q11), not a measurement. Recommended, ranked 3, in §20.2.
