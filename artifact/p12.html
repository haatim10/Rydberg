Appendix C

Glossary

Biased phase retrieval
Recovering complex x from z = |Ax + b + w| where the bias b is known. The bias is what makes the phase recoverable at all.
Cadzow denoising
Alternating projection between "rank ≤ L" (SVD truncation, exact by Eckart–Young–Mirsky) and "Hankel" (anti-diagonal averaging). Approximates the nearest fixed-rank Hankel matrix; not the exact projection.
CCRB
Constrained Cramér–Rao bound. The bound for an estimator that knows the parameters lie on a manifold. Computed here in Gorman–Hero / Stoica–Ng tangent-space form.
CRN
Common random numbers. Here: all estimators at one operating point see bit-identical realizations, which makes the paired bootstrap valid. Not shared across operating points.
Constraint active
A trial in which L̂ < cap(N), so the projection actually changes the iterate. When inactive, HS-GS returns EM-GS bit-for-bit.
EM-GS
Cui's Algorithm 2. Gerchberg–Saxton with the hard modulus substitution replaced by the exact Rician posterior mean of the phase factor, via the Bessel ratio R(κ).
Efficient
An unbiased estimator attaining the CRLB. EM-GS is close to efficient against the corrected unconstrained bound at high SNR with P = 30.
Hankel matrix
Constant along anti-diagonals. Built here from one channel column with pencil parameter p, giving shape (N−p) × (p+1).
HS-GS
Hankel-Structured GS. The proposed estimator: EM-GS with a Cadzow rank projection applied after every iteration. Order selected from held-out pilots, not oracle.
Kronecker's theorem
A length-N sequence is a sum of L complex exponentials iff its Hankel matrix has rank L (subject to converse conditions). The basis of the structural prior.
Rank cap
⌈N/2⌉ — the largest rank the Hankel matrix can have, maximised over pencil choice. When Lk ≥ cap the low-rank constraint is vacuous.
Ratio of sums
The pooling used throughout: 10 log₁₀(Σet/Σdt). Estimates the ensemble NMSE, which is the quantity a CRLB bounds.
RSR
Reference-to-signal ratio, Cui eq. 37, single-user denominator. 12 dB nominal here corresponds to 7.15 dB against the K-user total.
Row separability
Row n of GS affects only measurement row n, so the Fisher matrix is block diagonal across rows. This is why the unconstrained bound and the exact-model estimators are flat in N.
Shrinkage bias
Systematic pull of an estimate toward zero, c = ⟨Ĝ,G⟩/‖G‖² < 1. Permits MSE below the CRLB, which is why 63 of 108 combinations cross it.
Tie
A trial where HS-GS and EM-GS produce bit-identical output because the constraint was inactive. Dominates the raw win rate at N = 8 and must be quoted alongside it.
