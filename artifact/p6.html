Part X

Cramér–Rao lower bound

Derived for this measurement model, not adapted from a linear-Gaussian MIMO result. The derivation below also uncovered a defect in the bound previously plotted.

10.1 Likelihood verified

Conditional on G, S, B, the noiseless field at (n,p) is λ = (GS+B)n,p, a known complex constant. The measurement is z = |λ + w| with w ~ 𝒞𝒩(0,σ²): the modulus of a complex Gaussian with non-zero mean. That is by definition Rice-distributed with non-centrality |λ| and scale σ:

p(z | λ) = (2z/σ²) exp(−(z²+|λ|²)/σ²) I0(2z|λ|/σ²)(29)

Measurements are independent across (n,p) because W is i.i.d., so the joint log-likelihood is the sum. Critically, eq. (29) depends on λ only through |λ| — the phase of λ does not appear. This single fact drives everything in §10.3.

10.2 Parameterisation

Two parameterisations are needed, for two different bounds.

Unconstrained. Treat G as free: η = [vec(ℜG); vec(ℑG)] ∈ ℝ2NK. At N = 32, K = 3 that is 192 real parameters.

Structural. Use the generative parameters: φ = {ψℓ,k, ℜαℓ,k, ℑαℓ,k} ∈ ℝ3ΣLk — three real numbers per path, ≈45 in total, independent of N. §10.7 uses this.

10.3 Fisher information — and a defect in the previously plotted bound

Since eq. (29) depends only on a = |λ|, differentiate the log-likelihood with respect to a, using d/dx log I₀(x) = I₁(x)/I₀(x) = R(x):

∂ log p / ∂a = (2/σ²) [ z R(κ) − a ],   κ = 2za/σ²(30)

The score has zero mean, which immediately gives the identity E[z R(κ)] = a. Hence the scalar Fisher information of one measurement is

I(a) = (4/σ⁴) ( E[z²R²(κ)] − a² ) = 4β(31)

with β the quantity the existing code already computes by quadrature. Now the chain rule to the real channel coordinates. With ck = e−j∠λSk,p:

∂a/∂ℜGn,k = ℜ(ck),   ∂a/∂ℑGn,k = −ℑ(ck)(32)
J = Σn,p I(anp) (∇a)(∇a)T,   block diagonal across n(33)
Defect: each magnitude measurement contributes rank 1, not rank 2

Eq. (33) gives each measurement a rank-1 contribution in real coordinates — correct, because a magnitude measurement yields one real number. The implementation inherited from Track A uses F = Σ β m mH, whose real embedding has rank 2 per measurement, crediting each measurement with constraining both quadratures. Two independent tests:

(i) Rank / identifiability. With K = 3 (6 real unknowns) and P = 3 measurements the problem is manifestly unidentifiable. Eq. (33) gives Fisher rank 3 — correctly singular. The old construction claims real-equivalent rank 6.

(ii) Empirical. ML is asymptotically efficient. Measured over 4 000 noise realisations at K = 1, P = 8: ML MSE / rank-1 bound = 0.961× at 25 dB and 0.990× at 35 dB — converging onto it; ML MSE / old bound = 1.035× and 1.066×, i.e. ML sits above the old bound, which is therefore valid but loose by up to 4.2 dB, worst as P approaches 2K.

Why the standard check missed it. Both constructions satisfy the 10log₁₀2 high-SNR gap asymptotically, because a sum of rank-1 terms with spread phases averages to ½·SSH. That check validates the σ² convention and scaling, not the rank structure. Every bound in this document uses eq. (33). No estimator result changes.

10.4 Identifiability

  • Without a reference (B = 0) the likelihood depends only on |GS|. Any global phase rotation G → Gejφ leaves every measurement unchanged, so the FIM is singular along that direction and G is at best recoverable up to a phase. With per-row independence the ambiguity is per-row, which is worse.
  • With B ≠ 0 the cross term of eq. (7) ties ∠G to the known ∠B, breaking the ambiguity. This is the reason the reference exists.
  • Residual singularity conditions. Eq. (33) is a sum of P rank-1 terms in a 2K-dimensional space per row, so J is singular whenever P < 2K — which is exactly the P ≥ 2K floor the pilot generator enforces. It can also be singular if the ∇a directions fail to span, which happens if the pilot matrix is rank-deficient (prevented by rejection sampling) or if λ ≈ 0 at many measurements (prevented by a strong reference).
  • Roles. P supplies the measurements per row and must exceed 2K. K sets the unknowns per row. N adds rows, and — for the unconstrained bound — adds unknowns at exactly the same rate, which is why that bound is flat in N. Only under the structural parameterisation does N help (§10.7).

10.5 Numerical procedure — and which averaging is correct

No useful closed form exists: β requires quadrature of eq. (29). The implemented procedure is:

  1. For each channel realisation, compute λ = GS+B and β at every (n,p).
  2. Assemble J per receive element, eq. (33). Invert per block.
  3. Accumulate Tr(J−1) and ‖G‖F² separately.
  4. Take the ratio of the accumulated sums, then convert to dB.

This ordering matters and it is the theoretically correct one. The CRLB is conditional on G: for a given channel it bounds E[‖Ĝ−G‖²|G] ≥ Tr(J(G)−1). Averaging over channels, the valid statement is EGE[‖Ĝ−G‖²] ≥ EG[Tr(J−1)] — a ratio of expectations, matching the ratio-of-sums NMSE definition in §XII. Averaging dB values of per-realisation bounds would be a geometric mean and would not bound the arithmetic-mean NMSE.

β is tabulated once per operating point (σ² is fixed there and β is smooth in a); measured table accuracy is max relative error 2.7e−4, three orders of magnitude below the sampling noise it removes. The bound depends only on (G,S,B,σ²) — no noise realisation — so the only variability is the channel draw, and all bounds here are averaged over the same 400 trial indices the estimators saw.

10.6 NMSE-normalised bound

CRLBdB = 10 log10 ( Σtrials Σn Tr(Jn−1) / Σtrials ‖G‖F² )(34)

Both numerator and denominator are real energies, so the ratio is directly comparable to NMSEG. Note ‖Ĝ−G‖F² for complex G equals the sum of squared errors over all real coordinates, which is exactly what Tr of the real covariance returns — the factor of 2 is already handled, and E‖G‖F² = NKβ.

10.7 Which bound applies to HS-GS

The CRLB is a property of the observation model plus the parameter set, not of an estimator. GS and EM-GS estimate 2NK free parameters, so the unconstrained bound governs them. HS-GS constrains G to the geometric manifold, so the unconstrained bound does not govern it and placing HS-GS against it is invalid. The correct object is the constrained (Gorman–Hero / Stoica–Ng) bound. With D = ∂g/∂φ the manifold Jacobian:

CCRB = U(UTJU)−1UT,    U = orthonormal basis of range(D)(35)
Why the orthonormal form, not (DTJD)+

The path parameterisation is overcomplete whenever 3ΣLk exceeds the ambient dimension 2NK: at N = 8 that occurs in 42.5% of trials (3ΣLk reaches 63 against 2NK = 48). There the map φ → G is not injective and DTJD is genuinely singular. The bound is still well defined — it depends on the tangent space range(D), not on φ being identifiable — but pseudo-inverting gave condition numbers up to 6.8e17. The orthonormal form brings that to a worst case of 80 (median 5.3) and changes the answer where the overcompleteness bites: at N = 8, P = 10, SNR = 5 the bound moves from −4.41 to −3.40 dB.

Other candidate bounds, and why they are not used. A sparse/parametric CRLB on (α, θ) alone is what eq. (35) already is, pushed forward to the channel. A biased-estimator bound would be the strictly correct object for HS-GS, which is biased — but it requires knowing the bias gradient, which is not available in closed form. This is stated as a limitation rather than papered over: §XIII shows two N = 8 points sitting slightly below the constrained bound, and that is the expected consequence.
