Upload the Overleaf ZIP into a new project and choose `main.tex` with pdfLaTeX.
Choose `supplement.tex` to build the supporting document. The source package
includes its figures, bibliography, support and evidence files. It does not
require a new simulation run to compile.

The main text was shortened and uses simpler English. Figure 5 was redrawn;
the supplement retains the full BER range. Zero observed bit errors are not
replaced by an invented positive rate for a logarithmic plot.

The manuscript includes the receiver and baseline work completed for that
version. The subsequent URformer reproduction, matched-training comparison and
SNR/cluster audits are archived separately and **are not yet incorporated into
the manuscript**. The suggested uncertainty-based filter is also not a result.

See [the manuscript index](../../../paper/README.md) for earlier drafts. They are
retained for provenance, not presented as additional current submissions. This
GitHub organization did not alter manuscript text, figures or numerical results.
